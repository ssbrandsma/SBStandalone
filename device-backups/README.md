# Device Backups

This directory records applet backups taken from radios during development. It is not required for a normal installation.

Standalone Radio installs only its own directory at `/usr/share/jive/applets/StandaloneRadio/`; it does not modify stock SqueezePlay files. Keeping a copy of the deployed applet is still useful before upgrades or experimentation.

If a future feature genuinely requires changing a stock file, first copy the original file here and record the firmware version, original remote path, and reason for the change. Do not overwrite an existing backup.
