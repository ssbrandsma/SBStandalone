# Standalone Radio 0.9.18

Released 26 October 2026. Includes the native UBIFS/custom-station and exact-name
station-logo fixes from 0.9.17 plus the approved LMS handoff changes:

- Capture imports before the isolated Jive Lua module environment is entered.
- Patch the managed ChooseMusicSource instance after each load/reopen, while
  preserving existing loader adapters and background playback isolation.
- Select the actual LocalPlayer when explicitly starting a station, preventing
  an orphan remembered player from receiving a later library-switch request.
  Background reconnects do not change player selection.

All 23 Lua suites pass, including isolated-module/managed-chooser lifecycle,
local-player ownership, background reconnect, storage and logo regressions.
Physical LMS switching remains dependent on the external LMS being reachable;
these tests do not certify that network path.

Published as a new immutable package rather than modifying 0.9.17. Deployment
includes the complete StreamPlayer changes, with prior files archived. Base
code is unchanged; only its bundled Radio catalog metadata is updated.

ZIP SHA-1: `cc13a8e7c298cc9a4a32b34524d5c74d232b345e`. Published package,
standalone/merged XML and live bootstrap config were verified. All 24 installed
Radio files were hash-checked; stock Jive/audio backend/watchdog remained running
after the UI restart on 192.168.1.228.
