# Standalone Radio 0.9.17

Released 26 October 2026.

- Custom stations and OPML directories recognize native UBIFS extended storage,
  alongside legacy sbubifs, using the same exact volume checks as Base.
- Missing, ICO and failed station logos get a conservative exact-name TuneIn
  fallback. Placeholder, podcast and ambiguous results retain the generic icon.
- Lookup/download requests coalesce. Negative results have bounded one-hour
  caching. Images and their discovered URLs are cached under the original UUID.
- Discovered logos publish through the existing native Now Playing station-art
  API, including cache hits after restart; current track artwork keeps priority.

The audited general storage checks in Base already accept both filesystem names;
Base needs no code release for these fixes. Its local catalog and the bootstrap
JSON/XML catalogs were updated to reference Radio 0.9.17.

Validation: 21 release Lua suites, changed-module Lua 5.1 parsing, package/catalog
checksums, public HTTP downloads, live bootstrap config and radio file hashes.
DR P1/P3/P5 literal TuneIn searches returned unique PNG logos. P2/P4/P6 had no
literal exact match; differently named channels are not guessed. The Radio's
DR P1 HTTP download matched the independently fetched PNG's checksum.

Published ZIP SHA-1: `5905476cba373ba7f5f19cb5543e475f12d375cd`.
Deployed to 49.12.198.91 and 192.168.1.228. Radio deployment preserved existing
uncommitted StreamPlayer handoff changes, which are excluded from this package
and release commit. Stock Jive and its audio backend were verified after restart.

0.9.16 was an intermediate publication; 0.9.17 completes the native Now Playing
logo integration. Versioned ZIPs were not overwritten.
